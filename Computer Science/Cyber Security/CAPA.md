CAPA or Common Analysis Platform for Artifacts is **a tool used for static analysis of executables**.
# Cheat Sheet
```powershell
# Run CAPA on a specific binary
capa .\binary.bin

# Display help
capa /h

# Use verbose or extra verbose for results
capa .\binary.bin /v
capa .\binary.bin /vv
```
