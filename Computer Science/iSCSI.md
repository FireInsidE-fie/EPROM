Internet Small Computer Systems Interface or iSCSI is a protocol **layering [[Small Computer System Interface]] over the [[Transmission Control Protocol]]**.
This negates the need for dedicated ports and physical connections, and instead means you **can run SCSI on any network supporting the [[Internet Protocol]]**.
This is especially useful for data transfers over [[Intranet]]s, and to manage storage over long distances.
