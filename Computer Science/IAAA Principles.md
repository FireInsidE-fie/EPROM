The IAAA Model or IAAA Principles is a list of core values in security:
1. **Identification**: Verify who the user is.
   You do this based on unique identifiers, such as email addresses, or usernames.
2. **Authentication**: Ensure the user is who they claim to be.
   Typically, this happens through passwords or passkeys.
3. **Authorization**: Verify that the user has the rights to access the given resource.
   This usually is implemented through roles for users and permissions for resources.
4. **Accountability**: Track the user activity to ensure they are responsible for their actions.
   Logging is the main way to achieve accountability.
