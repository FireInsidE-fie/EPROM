Extensible Markup Language or XML is a language used to **store, transmit and reconstruct data**.
It **defines rules for encoding data in a format that is both human-readable, and machine-readable**.
Its main purpose it to **serialize data, in order to facilitate its transmission and storage**.
# XML's Big Family
XML is so useful, a lot of applications and services use it for their document formats.
