An RPC or Remote Procedure Call is **an action where a computer launches a subroutine in a different adress space of the current process**. Often, this is on another computer of a network.
The mechanism has to be written as if it was a local call, and the programmer **shouldn't have to care about writing the remote-launching mechanism**.
