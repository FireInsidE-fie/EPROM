Gateways are **hardware or software that allows data to flow from one network to another**.
Gateways **aren't necessarily [[Router]]s or [[Switch]]es, as they can operate on any level of the [[OSI Model]]**.
However, the term *gateway* could refer to a computer or other piece of hardware **configured to act as a gateway** in a given network.
Often, this is a job of a network's [[Router]], whose best example is **a home's wifi router connecting the home's intranet to the wider Internet**.
# Default Gateways
A default gateway is, on a networking using the [[Internet Protocol]] suite, **the gateway that will be used to forward traffic when no other route specifically match the destination [[IP Address]] of a packet**.
This means that if the [[Routing Table]] doesn't include an entry related to the packet's destination, the default gateway will be used instead.
Usually, in a home or small enterprise environment, the default gateway will be the local [[Router]].
