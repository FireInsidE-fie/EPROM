The LDAP protocol is an open protocol for **accessing and managing directory information services over an [[Internet Protocol]]**.
# Directory Services
Directory services are important to **maintain [[Intranet]] and Internet applications**.
They do this by allowing the sharing of information, such as users, systems, networks, services, or applications throughout the network.
For example, a directory service might **provide a list of corporate emails for a business, or of telephone numbers for a website**.
# Common Uses
A common use of LDAP is to **provide a central place to store a list of users and passwords**.
This allows many different applications to connect to the LDAP server to **validate users**.
LDAP is the basis for a lot of modern Internet protocols, such as:
- [[Active Directory]]
- [[Directory Service Markup Language]]
- [[Service Location Protocol]]
- etc.
