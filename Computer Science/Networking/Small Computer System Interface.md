Small Computer System Interface or SCSI is **a set of standards for linking peripheral devices, and transmitting data between them**.
It is **most widely used with storage devices, like hard drives**.

# Interfaces
SCSI is **available in a variety of interfaces, or connectors**.
The first of theses was *parallel SCSI, also called SCSI Parallel or SPI*. It used a [[Parallel Bus]] design.
Nowadays, SPI has been replaced with *serial attached SCSI or SAS*. This connector main change is that it uses a [[Serial]] design.
Meanwhile, [[iSCSI]] takes a different approach by **doing away with dedicated physical connectors**.
Instead, iSCSI transports data over TCP/IP, most often using Ethernet cables.
