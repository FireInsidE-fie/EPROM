A Logical Unit Number or LUN is a number used to **identify a Logical Unit** in computer storage systems.
A *logical unit* is a **device addressed by the [[Small Computer System Interface]] protocol, or by [[Storage Area Network]] protocols that encapsulate SCSI, like [[Fibre Channel Protocol]] or [[iSCSI]]**.
A LUN can be used with any device that supports read and write operations, but it is most often used to referer to a *logical disk* created on a SAN.
Sometimes, LUN also incorrectly refer to the logical disk itself.
